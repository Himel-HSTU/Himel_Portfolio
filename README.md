## 🏗️ Project Architecture

Built with a component-based architecture using Blazor WebAssembly, with a separation of UI components, application pages, layouts, models, and portfolio data.

```text
Himel_Portfolio/
│
├── Components/       # Reusable UI components
├── Data/             # Portfolio content and data
├── Layout/           # Application layouts
├── Models/           # Data models
├── Pages/            # Portfolio pages and routes
├── Properties/       # Project configuration
│
├── wwwroot/          # Static assets, stylesheets, scripts
│
├── App.razor         # Root application component
├── Program.cs        # Application entry point
├── _Imports.razor    # Shared Razor imports
│
└── HimelPortfolio.csproj
```

## ☁️ Deployment

The website is hosted on **Cloudflare Pages**, integrated with GitHub for automated deployments.

The production workflow is straightforward:

1. Changes are committed and pushed to the GitHub repository.
2. Cloudflare Pages detects updates to the production branch.
3. The project is built using the .NET 10 SDK.
4. The published Blazor WebAssembly assets are deployed to Cloudflare's global network.

**Deployment Configuration**

| Setting                | Configuration     |
| :--------------------- | :---------------- |
| Hosting Platform       | Cloudflare Pages  |
| Framework Preset       | None              |
| Build Output Directory | `publish/wwwroot` |
| Production Branch      | `main`            |
